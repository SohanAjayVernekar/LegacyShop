This fixes the broken/invisible 3D hero and changes the 2000-product catalog from
mostly home/decor products into a broad general marketplace.

Main departments include:
Electronics, Mobiles & Tablets, Computers, TV & Audio, Cameras, Gaming,
Home & Kitchen, Furniture, Lighting, Decor, Appliances, Men's Fashion,
Women's Fashion, Shoes, Bags, Jewelry, Watches, Beauty, Health & Wellness,
Grocery, Books, Sports, Toys, Baby, Automotive, Pet Supplies, Office,
Garden, Tools, Musical Instruments, Gifts, and Travel Accessories.

Apply:

```bash
cd ~/Downloads/LegacyShop_ZeroToMVP
unzip -o ~/Downloads/LegacyShop_Stage4B_Fix.zip -d .
chmod +x scripts/stage4b-all-types.sh
./scripts/stage4b-all-types.sh
```

Then open:

```text
http://localhost:8040
```

Hard refresh:

```text
Ctrl + Shift + R
```
